

# Dashboard Xboxgamepass com excel

Este repositório contém o **Dashboard Game Pass 2024**, uma ferramenta interativa desenvolvida para análise de dados relacionados às assinaturas do serviço **Game Pass Ultimate**. O dashboard foi projetado para fornecer insights detalhados sobre os padrões de assinatura, renovação automática e vendas de pacotes adicionais, como **EA Play Season Pass** e **Minecraft Season Pass**.

Disponivel no arquivo Dashboard_gamepass_2024_Final.xlsx

## Funcionalidades

- **Visualização de Dados**: Apresentação gráfica dos principais indicadores, incluindo:
  - Percentual de assinantes que optaram pela renovação automática, categorizados por tipo de assinatura.
  - Distribuição mensal das novas assinaturas por tipo.
  - Total de vendas dos pacotes adicionais (**EA Play Season Pass** e **Minecraft Season Pass**).
  
- **Estilo Personalizado**:
  - Paleta de cores otimizada para facilitar a interpretação dos gráficos:
    - Verde (#9BC848) para dados positivos.
    - Cinza claro (#E8E6E9) para zonas negativas.
    - Tons vibrantes (#2AE6B1 e #5BF6A8) para menus e seções.
  
- **Base de Dados Completa**:
  - Informações detalhadas sobre os assinantes, incluindo nome, plano, data de início, tipo de assinatura, preços e valores totais.

## Estrutura do Arquivo

O arquivo Excel utilizado no projeto possui as seguintes abas:
- **Assets**: Contém as configurações visuais e paleta de cores.
- **Base**: Dados brutos dos assinantes e suas assinaturas.
- **Cálculos**: Respostas às perguntas de negócio com agregações e somatórios.
- **Dashboard**: Interface principal do dashboard (em desenvolvimento).
- **Extras**: Espaço reservado para futuras implementações.
